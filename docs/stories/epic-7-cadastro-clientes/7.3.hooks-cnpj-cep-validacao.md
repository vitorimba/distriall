## Story
**As a** vendedor,
**I want** que ao digitar um CNPJ ou CEP o sistema auto-preencha os dados,
**so that** eu nao precise digitar manualmente razao social, endereco e outros dados publicos.

## Scope
### IN
- Hook `useCnpjLookup(cnpj)`: consulta CNPJ.ws → fallback BrasilAPI → retorna dados empresa
- Hook `useCepLookup(cep)`: consulta ViaCEP → retorna endereco
- Funcao `validateCpf(digits)`: validacao por checksum (mod 11)
- Funcao `validateCnpj(digits)`: validacao por checksum (mod 11)
- Funcao `unmask(value)`: remove tudo que nao e digito
- Debounce de 1.5s no CNPJ lookup (rate limit CNPJ.ws = 3/min)
- Testes unitarios para validacao CPF/CNPJ

### OUT
- Integracao com o form (Story 7.4)
- Componentes UI (Story 7.4)

## Dependencies
- `mask-utils.ts` existente com `maskCEP()`, `maskCpfCnpj()` — ja pronto

## Complexity
- **Estimate:** M
- **Points:** 5
- **Rationale:** 2 hooks com fallback + 2 funcoes de validacao + testes

## Risks
- **R1:** API CNPJ.ws fora do ar. **Mitigacao:** Fallback automatico para BrasilAPI; form continua funcional sem auto-fill.
- **R2:** Rate limit CNPJ.ws (3/min free). **Mitigacao:** Debounce 1.5s + fallback.

## Acceptance Criteria
1. **Given** um CNPJ valido, **When** chamo `useCnpjLookup`, **Then** retorna razao social, nome fantasia, endereco, telefone, email
2. **Given** CNPJ.ws indisponivel, **When** chamo `useCnpjLookup`, **Then** fallback para BrasilAPI automaticamente
3. **Given** um CEP valido, **When** chamo `useCepLookup`, **Then** retorna logradouro, bairro, cidade, UF
4. **Given** CPF "529.982.247-25" (valido), **When** chamo `validateCpf`, **Then** retorna true
5. **Given** CPF "111.111.111-11" (invalido), **When** chamo `validateCpf`, **Then** retorna false
6. **Given** CNPJ "11.222.333/0001-81" (valido), **When** chamo `validateCnpj`, **Then** retorna true
7. **Given** ambas APIs fora do ar, **When** chamo `useCnpjLookup`, **Then** retorna erro gracioso sem quebrar a UI
