## Story
**As a** vendedor,
**I want** um formulario de cadastro que se adapta entre PF e PJ, com auto-preenchimento ao digitar CNPJ,
**so that** eu cadastre clientes rapidamente e com dados corretos para NF-e.

## Scope
### IN
- Toggle PF/PJ no topo do form
- Labels dinamicos: "Nome"/"Razao Social", "CPF"/"CNPJ"
- Campo documento com mascara visual (CPF: 000.000.000-00, CNPJ: 00.000.000/0001-00)
- Campo IE (so aparece em PJ)
- Campo email
- Auto-fill CNPJ: ao perder foco com 14 digitos, consulta API e preenche campos vazios
- Validacao CPF/CNPJ por checksum antes de salvar
- Indicador visual de loading durante consulta CNPJ
- Nunca sobrescrever campos que o usuario ja preencheu

### OUT
- CRUD de enderecos (Story 7.5)
- Seletor de endereco no pedido (Story 7.6)

## Dependencies
- Story 7.1 — campos `type`, `document`, `state_registration`, `email` no banco
- Story 7.3 — hooks `useCnpjLookup`, `useCepLookup`, validacao

## Complexity
- **Estimate:** L
- **Points:** 8
- **Rationale:** Form complexo com logica condicional, auto-fill async, mascaras, validacao

## Risks
- **R1:** Auto-fill sobrescreve dados do usuario. **Mitigacao:** Checar campo vazio antes de preencher (principio nao-negociavel).
- **R2:** UX confusa no toggle PF/PJ. **Mitigacao:** Design simples com 2 botoes (Pessoa Fisica / Pessoa Juridica).

## Acceptance Criteria
1. **Given** o form em modo PJ, **When** vejo os labels, **Then** exibe "Razao Social", "CNPJ", "Inscricao Estadual"
2. **Given** o form em modo PF, **When** vejo os labels, **Then** exibe "Nome", "CPF" e IE esta oculto
3. **Given** modo PJ e CNPJ preenchido, **When** perco foco do campo CNPJ, **Then** sistema consulta API e preenche campos vazios
4. **Given** campo "Razao Social" ja preenchido pelo usuario, **When** auto-fill retorna, **Then** campo NAO e sobrescrito
5. **Given** CPF invalido digitado, **When** tento salvar, **Then** form mostra erro de validacao
6. **Given** consulta CNPJ em andamento, **When** vejo o form, **Then** exibe spinner/loading no campo CNPJ
7. **Given** API CNPJ indisponivel, **When** perco foco do CNPJ, **Then** form continua funcional sem auto-fill (erro silencioso)
8. **Given** cliente existente em modo edicao, **When** abro o form, **Then** campos preenchidos com dados atuais incluindo type, document, email
