## Story
**As a** administrador,
**I want** que os enderecos ja cadastrados nos clientes sejam migrados para a nova tabela `client_addresses`,
**so that** clientes existentes nao percam seus dados e ja tenham enderecos estruturados.

## Scope
### IN
- Script SQL que migra `clients.address`, `clients.city`, `clients.neighborhood` para `client_addresses`
- Cada cliente com endereco preenchido ganha 1 registro em `client_addresses` com label "Principal"
- Enderecos migrados recebem `is_default_delivery=true` (ja era o endereco unico)
- Manter campos antigos intactos (nao deletar colunas legacy)

### OUT
- Deletar colunas `address`, `city`, `neighborhood` do clients (futuro)
- Migrar CPF/CNPJ (nao existe hoje)

## Dependencies
- Story 7.1 — tabela `client_addresses` deve existir

## Complexity
- **Estimate:** S
- **Points:** 3
- **Rationale:** Script INSERT simples a partir de dados existentes

## Risks
- **R1:** Clientes sem endereco geram registro vazio. **Mitigacao:** WHERE clause filtra apenas clientes com pelo menos 1 campo preenchido.

## Acceptance Criteria
1. **Given** clientes com endereco preenchido, **When** a migration roda, **Then** cada um tem 1 registro em `client_addresses` com label "Principal" e `is_default_delivery=true`
2. **Given** clientes sem endereco (address, city, neighborhood todos NULL), **When** a migration roda, **Then** nenhum registro e criado para eles
3. **Given** a migration completa, **When** conto registros em `client_addresses`, **Then** o total bate com clientes que tinham endereco

## Technical Notes
### Arquivos a criar
- `supabase/migrations/00026_migrate_client_addresses.sql`

### Logica
```sql
INSERT INTO client_addresses (client_id, account_id, label, street, neighborhood, city, is_default_delivery)
SELECT id, account_id, 'Principal', address, neighborhood, city, true
FROM clients
WHERE address IS NOT NULL OR city IS NOT NULL OR neighborhood IS NOT NULL;
```
