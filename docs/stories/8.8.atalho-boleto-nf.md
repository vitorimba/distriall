## Story
**As a** Tiago (admin),
**I want** copiar rapidamente os dados do pedido (cliente, CNPJ/CPF, itens, valor) para colar no sistema de boleto/NF externo,
**so that** eu nao precise digitar tudo de novo quando for gerar boleto e nota fiscal de manha.

## Contexto (fala do Tiago)
> "eu chego de manhazinha aqui, eu bato os boletos, eu que faco os boletos, nota fiscal e boleto aqui dos meus pedidos"

## Problema
Tiago gera boletos e NF todo dia de manha num sistema externo (Boa Mesa). Hoje ele precisa re-digitar todos os dados do pedido manualmente. O app marca boleto como `is_third_party: true` e exibe "(Boa Mesa)" mas nao tem nenhum link ou atalho para o sistema externo.

## Scope

### IN
- Botao "Copiar dados para NF/Boleto" no detalhe do pedido (pedidos com pagamento boleto)
- Texto copiado inclui: razao social, CNPJ/CPF, endereco, itens com quantidade e valor, total
- Formato estruturado para facil cole no sistema externo
- Visivel apenas quando pedido tem pagamento tipo "boleto"

### OUT
- Integracao direta com API da Boa Mesa ou qualquer emissor de NF
- Geracao automatica de boleto dentro do app
- Squad NF completo (SEFAZ, DANFE, XML)
- Modificacao do fluxo de pagamento existente

## Dependencies
- **Story 3.1** (Formas de Pagamento) — DONE
- **Story 7.4** (Client Form PF/PJ) — Draft (para ter CNPJ/CPF — funciona sem, apenas omite campo)

## Complexity
- **Estimate:** S (Small)
- **Points:** 2
- **Rationale:** 1 botao + funcao de formatacao. Zero migration, zero componente novo. Apenas concatena dados que ja existem no pedido.

## Acceptance Criteria
1. No detalhe do pedido, se pagamento inclui "boleto", botao "Copiar dados NF" visivel
2. Ao clicar, copia texto formatado para clipboard:
   ```
   DADOS PARA NF/BOLETO
   Cliente: [nome]
   CPF/CNPJ: [se disponivel]
   Endereco: [endereco completo]
   
   ITENS:
   - Produto A x 10 = R$ 150,00
   - Produto B x 5 = R$ 80,00
   
   TOTAL: R$ 230,00
   Pedido #: [numero]
   Data: [data do pedido]
   ```
3. Toast "Dados copiados!" de confirmacao
4. Se cliente nao tem CNPJ/CPF cadastrado, campo aparece como "[nao cadastrado]"

## Tasks / Subtasks
- [ ] Task 1: Funcao de formatacao (AC: #2, #4)
  - [ ] 1.1 Criar util `formatOrderForInvoice(order, client, items)` 
  - [ ] 1.2 Incluir dados do cliente, itens, total, numero do pedido
  - [ ] 1.3 Tratar campo CNPJ/CPF ausente
- [ ] Task 2: Botao no detalhe do pedido (AC: #1, #3)
  - [ ] 2.1 Adicionar botao condicional (so aparece se tem pagamento boleto)
  - [ ] 2.2 `navigator.clipboard.writeText()` + toast

## Risks
- **Clipboard API:** `navigator.clipboard.writeText()` pode falhar em contextos inseguros (HTTP sem HTTPS) ou em navegadores antigos. Mitigacao: fallback com `document.execCommand('copy')` ou toast de erro orientando o usuario.
- **Dados incompletos:** Se pedido nao tiver endereco ou itens carregados, texto copiado fica incompleto. Mitigacao: tratar campos ausentes com placeholder "[nao disponivel]".
