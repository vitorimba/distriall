## Story
**As a** operador do DistriAll,
**I want** ver um preview do recibo termico e imprimir via Bluetooth,
**so that** eu possa entregar comprovante ao cliente no ato da entrega.

## Acceptance Criteria
1. Componente Receipt renderiza recibo P&B (tokens --receipt-*) para 58/80mm
2. Dialog de preview mostra Receipt em tamanho real
3. Botao "Imprimir" no Dialog tenta Web Bluetooth (Chrome/Edge Android)
4. Fallback: imprimir via window.print() com CSS @media print
5. Receipt identico nos dois temas (dark/light) — cores fixas
