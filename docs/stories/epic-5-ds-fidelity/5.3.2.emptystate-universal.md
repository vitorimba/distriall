## Story
**As a** usuario do DistriAll,
**I want** ver estados vazios informativos com icone, titulo e acao,
**so that** eu saiba o que fazer quando uma lista esta vazia.

## Acceptance Criteria
1. Toda lista vazia usa `<EmptyState icon={...} title="..." description="..." actionLabel="..." onAction={...} />`
2. Copy canonica: "Nenhum pedido ainda" + "Lance o primeiro pedido para ve-lo aqui."
3. Icone correto por contexto (clipboard-list para pedidos, users para clientes, etc.)
4. Acao primaria quando fizer sentido (ex: "Novo pedido" na lista vazia de pedidos)
5. Variante error quando aplicavel (icon alert-circle, tone danger)
