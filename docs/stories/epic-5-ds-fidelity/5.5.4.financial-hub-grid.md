## Dev Notes

### Referencia canonica no DS

`packages/design-system/ui_kits/distriall/FinancialHubScreen.jsx` — tela de referencia. Estrutura-chave:

```jsx
import { Icon } from '../../components/core/Icon';

const SECOES = [
  { id: 'settlements', icon: 'scale',   titulo: 'Acertos',  desc: 'Fechamento por período: faturamento, custos, despesas e lucro líquido.' },
  { id: 'expenses',   icon: 'receipt',  titulo: 'Despesas', desc: 'Lançamento e acompanhamento de despesas operacionais.' },
  { id: 'vouchers',   icon: 'ticket',   titulo: 'Vales',    desc: 'Vales de clientes: pendentes, pagos e vencidos.' },
];

// Layout 3 colunas com classe DS
<div className="da-grid da-grid--cols3">
  {SECOES.map((s) => (
    <Card key={s.id}>
      <button onClick={() => onNavigate && onNavigate(s.id)} ...>
        <span style={{
          display: 'inline-flex', alignItems: 'center', justifyContent: 'center',
          width: 40, height: 40, borderRadius: 'var(--radius-md)',
          background: 'var(--accent-soft)', color: 'var(--accent-fg)',
        }}>
          <Icon name={s.icon} size={20} />
        </span>
        <span style={{ fontSize: 'var(--text-md)', fontWeight: 'var(--weight-bold)' }}>{s.titulo}</span>
        <span style={{ fontSize: 'var(--text-sm)', color: 'var(--text-secondary)' }}>{s.desc}</span>
        <span style={{ color: 'var(--accent-fg)', fontWeight: 'var(--weight-semibold)' }}>
          Abrir <Icon name="arrow-right" size={14} />
        </span>
      </button>
    </Card>
  ))}
</div>
// Empilha automaticamente abaixo de 768px via layout.css media query
```
