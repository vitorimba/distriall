## Acceptance Criteria
1. `maskPhone(value)` — formata fixo (00) 0000-0000 ou celular (00) 00000-0000
2. `maskCEP(value)` — formata 00000-000
3. `maskCpfCnpj(value)` — detecta CPF (000.000.000-00) ou CNPJ (00.000.000/0000-00) pelo tamanho
4. `maskMoney(value)` — digitos viram centavos: 123456 → 1.234,56
5. `parseMoney(formatted)` — converte "1.234,56" de volta para 1234.56
6. `isPhoneComplete(value)` — valida tamanho minimo
7. `MSG` — mensagens canonicas: "Campo obrigatorio", "Telefone incompleto", etc.
8. Testes unitarios para todas as funcoes com Vitest

## Dev Notes

### Contexto tecnico
- Criar `apps/web/src/lib/mask-utils.ts` — mesmo nivel que `utils.ts` e `delivery-utils.ts`
- Funcoes devem receber string (value) e retornar string mascarada
- `maskPhone`: 10 digitos = fixo `(00) 0000-0000`; 11 digitos = celular `(00) 00000-0000`
- `maskCpfCnpj`: ate 11 digitos = CPF; 12+ digitos = CNPJ
- `maskMoney`: recebe numero inteiro em centavos ou string numerica; retorna "1.234,56"
- `parseMoney`: recebe "1.234,56" retorna 1234.56 (float)
- `isPhoneComplete`: retorna true se celular (11 digitos) ou fixo (10 digitos) completo

### MSG — mensagens canonicas sugeridas
