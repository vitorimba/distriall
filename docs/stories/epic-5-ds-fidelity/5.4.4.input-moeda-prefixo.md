## Dev Notes

### Contexto Tecnico

**Input atual** (`apps/web/src/components/ui/input.tsx`):
- Componente simples wrapping `@base-ui/react/input`
- Aceita `React.ComponentProps<"input">` + `className`
- Altura `h-8`, padding `px-2.5 py-1`, `rounded-lg`, `border border-input`
- Nao tem suporte a `prefix` — deve ser estendido

**Padrao recomendado para prefix:**
Envolver `Input` em um container wrapper que renderiza o prefixo como `span` a esquerda. O `Input` recebe `rounded-l-none` e o span recebe `rounded-l-lg border-r-0`. Alternativa: adicionar prop `prefix?: React.ReactNode` ao componente `Input` que renderiza um wrapper interno. Prefira a segunda opcao (prop no Input) para manter uso uniforme em todos os call-sites.

```tsx
// Exemplo de extensao no input.tsx:
interface InputProps extends React.ComponentProps<"input"> {
  prefix?: React.ReactNode;
}
function Input({ className, type, prefix, ...props }: InputProps) {
  if (prefix) {
    return (
      <div className="flex items-center">
        <span className="inline-flex h-8 items-center rounded-l-lg border border-r-0 border-input bg-muted px-2.5 text-sm text-muted-foreground select-none">
          {prefix}
        </span>
        <InputPrimitive ... className={cn("rounded-l-none", className)} {...props} />
      </div>
    );
  }
  return <InputPrimitive ... />;
}
```

**Classe `.num` (tabular-nums):**
Adicionar ao `globals.css` ou aplicar via Tailwind: `className="tabular-nums"`. A classe Tailwind `tabular-nums` ja existe — usar diretamente (`className="tabular-nums num"` ou apenas `className="num"` se `.num` for definida no globals.css como alias de `tabular-nums`). Verificar se `.num` ja esta definida em `globals.css` antes de criar; se nao estiver, aplicar `tabular-nums` diretamente via Tailwind e renomear o AC para "classe tabular-nums".
