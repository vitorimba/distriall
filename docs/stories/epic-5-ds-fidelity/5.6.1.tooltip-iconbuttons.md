## Story
**As a** usuario do DistriAll,
**I want** ver tooltip descritivo ao passar o mouse sobre botoes de icone,
**so that** eu saiba o que cada botao faz sem clicar.

## Acceptance Criteria
1. Todo botao `size="icon"` envolto em `<Tooltip label="...">`
2. Tooltip aparece no hover e focus
3. Position `top` por padrao; usar `position="bottom"` manualmente quando o botao estiver proximo ao topo da viewport (ex: PageHeader onBack)
4. Cobrir areas: Sidebar (theme toggle), headers, acoes de tabela, PageHeader actions

## Dev Notes / Technical Notes

### Import do Tooltip
```typescript
import { Tooltip } from '@/components/ui/tooltip'
```

### Padrao de uso
```tsx
<Tooltip label="Descricao do botao">
  <Button variant="ghost" size="icon" aria-label="Descricao do botao">
    <Icon className="size-4" />
  </Button>
</Tooltip>
```
Manter `aria-label` existente no Button — o `aria-label` serve a leitores de tela, o Tooltip serve a usuarios de mouse/teclado visual.
