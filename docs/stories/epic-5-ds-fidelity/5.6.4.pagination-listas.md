## Story
**As a** gestor do distribuidor,
**I want** que listas com mais de 25 itens tenham paginacao,
**so that** a pagina carregue rapido e eu navegue entre paginas de resultados.

## Acceptance Criteria
1. Componente `Pagination` (REUSE `apps/web/src/components/ui/pagination.tsx`) renderizado abaixo de cada lista quando o total de itens exceder 25
2. Summary exibido no formato: "1–25 de 142 itens" (via prop `totalItems` e `label` do componente)
3. Navegacao prev/next e numeros de pagina funcionando (cliente-side slice da array em memoria)
4. Aplicado em 3 paginas: stats ranking (`ProductRankingTable`), orders list (`OrderList`), expenses list (`ExpenseList`)
5. Quando o total de itens for <= 25, o componente `Pagination` NAO e exibido

## Scope
**IN:**
- Paginacao client-side (slice da array local carregada em estado) nas 3 paginas alvo
- REUSE do componente `Pagination` existente em `apps/web/src/components/ui/pagination.tsx`
- Estado de pagina local por componente (`useState<number>`)
- Reset de pagina para 1 ao mudar filtros

**OUT:**
- Paginacao server-side com query LIMIT/OFFSET (fora do escopo — story futura se necessario)
- Novos componentes de paginacao (REUSE obrigatorio)
- Modificacoes no componente `pagination.tsx`

- Stats ranking pode ter poucas linhas em periodos curtos — condicional `totalItems > 25` garante que paginacao nao aparece desnecessariamente.

### Componente Pagination — API atual (REUSE obrigatorio)

```tsx
// apps/web/src/components/ui/pagination.tsx
interface PaginationProps {
  page?: number           // pagina atual (default 1)
  totalPages?: number     // alternativa a totalItems
  totalItems?: number     // total de itens (preferir esse)
  pageSize?: number       // itens por pagina (default 25)
  onChange?: (page: number) => void
  label?: string          // ex: "pedidos", "gastos", "produtos" (default "itens")
  className?: string
}
```

### Padrao de implementacao

```tsx
// Exemplo canonico (ProductRankingTable)
const PAGE_SIZE = 25
const [page, setPage] = useState(1)

// Slice APOS sort/filter
const paged = sorted.slice((page - 1) * PAGE_SIZE, page * PAGE_SIZE)

// Renderizar condicional
{sorted.length > PAGE_SIZE && (
  <Pagination page={page} totalItems={sorted.length} pageSize={PAGE_SIZE} onChange={setPage} label="produtos" />
)}
```

### Reset de pagina nos filtros (CRITICO para OrderList e ExpenseList)

Ao mudar `statusFilter`, `paymentFilter`, `search` (OrderList) ou `categoryFilter`, `typeFilter`, `dateFrom`, `dateTo` (ExpenseList), resetar `page` para `1`:

```tsx
// Adicionar setPage(1) nos handlers de filtro ou via useEffect
useEffect(() => { setPage(1) }, [statusFilter, paymentFilter, search])
```
