## Story
**As a** usuario do DistriAll,
**I want** ver confirmacao visual (toast) apos cada acao bem sucedida,
**so that** eu tenha certeza de que a acao foi processada.

## Acceptance Criteria
1. `useToast()` chamado apos toda acao de mutacao
2. Copy canonica: "Pedido #1047 salvo" (substantivo + acao no participio)
3. Toast some sozinho em ~3.2s
4. Tone: success (verde) para sucesso, danger (vermelho) para erro
