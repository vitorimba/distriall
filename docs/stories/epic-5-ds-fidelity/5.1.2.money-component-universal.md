## Story
**As a** dev do DistriAll,
**I want** usar o componente `<Money>` do DS para toda exibicao de moeda,
**so that** valores monetarios tenham tabular-nums, formato pt-BR e cor signed consistente.

## Acceptance Criteria
1. Zero ocorrencias de `formatBRL()` inline para exibicao (permitido em string interpolation nao-visual)
2. Todo valor monetario visivel usa `<Money value={n} />` ou `<Money value={n} signed />`
3. Valores positivos/negativos com cor correta quando `signed` (verde/vermelho)
4. Classe `.num` aplicada automaticamente pelo componente
