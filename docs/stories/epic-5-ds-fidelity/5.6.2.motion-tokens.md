## Story
**As a** dev do DistriAll,
**I want** que todas as transicoes usem os tokens de motion do DS,
**so that** a velocidade e curva de animacao sejam consistentes.

## Acceptance Criteria
1. Transicoes usam `var(--duration-*)` e `var(--ease-*)` em vez de `duration-200` do Tailwind
2. Dialog: fade + translateY(8) + scale(0.98), duration-base
3. Toast: fade + translateY(8), duration-base
4. Menu: fade + translateY(-3), duration-fast
5. BottomSheet: slide de baixo, duration-slow
6. Hover: duration-instant, ease-out
7. `@media (prefers-reduced-motion: reduce)` desliga animacoes

## Tasks / Subtasks

- [ ] Task 3: Adicionar reduced-motion media query
- [ ] Task 4: Audit: zero `transition-all duration-200` hardcoded
