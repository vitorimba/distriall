## Story
**As a** operador do DistriAll,
**I want** que inputs de telefone, CEP e moeda formatem automaticamente enquanto digito,
**so that** os dados fiquem padronizados sem eu precisar formatar manualmente.

## Acceptance Criteria
1. Client form: maskPhone em telefone e whatsapp, maskCEP em CEP (se existir no formulario)
2. Product form: maskMoney em precos de custo e venda (cost_price, sell_price nas variantes)
3. Expense form: maskMoney em valor (campo amount)
4. PaymentSelector (pagamento misto em orders/new): maskMoney nos inputs de amount por linha de pagamento misto
5. Mascaras aplicadas no onChange, nao no blur
6. Inputs de telefone/whatsapp com inputMode="tel"; inputs de valor com inputMode="numeric"
7. Estado React armazena string mascarada; conversao para numero (parseMoney) feita no handleSubmit antes de salvar

### Contexto tecnico

**Import padrao (estabelecido na story 5.4.1):**
```ts
import { maskPhone, maskMoney, parseMoney } from '@/lib/mask-utils'
```

**Arquivo real dos inputs de pagamento misto:**
- O `orders/new/page.tsx` delega o pagamento para `PaymentSelector` em `apps/web/src/components/financial/payment-selector.tsx`
- Os inputs de `amount` estao em `payment-selector.tsx` (linha ~138) — Task 4 deve editar ESTE arquivo

**Padrao de uso com estado React:**
```tsx
// Estado armazena string mascarada
const [phone, setPhone] = useState(client?.phone ?? '');

// onChange aplica mascara
onChange={(e) => setPhone(maskPhone(e.target.value))}

// inputMode para teclado correto
<Input inputMode="tel" value={phone} onChange={...} />
```

**Para inputs de moeda:**
```tsx
// Estado armazena string mascarada ex: "1.234,56"
const [amount, setAmount] = useState(
  expense?.amount ? maskMoney(String(Math.round(expense.amount * 100))) : ''
);

// onChange aplica mascara
onChange={(e) => setAmount(maskMoney(e.target.value))}

// No submit: converter para numero
const parsedAmount = parseMoney(amount); // retorna 1234.56
```

**Inputs de produto (cost_price/sell_price) — padrao com variantes:**
```tsx
// updateVariant recebe string mascarada
function updateVariant(index: number, field: string, value: string) {
  setVariants(variants.map((v, i) => (i === index ? { ...v, [field]: value } : v)));
}

// No submit: converter para number via parseMoney
const variantInput = { ...v, cost_price: parseMoney(v.cost_price as string), sell_price: parseMoney(v.sell_price as string) }
```

**PaymentSelector — modo misto:**
```tsx
// Input atual: type="number", value={p.amount || ''}
// Novo: type="text", inputMode="numeric", value={p.amountDisplay || ''}
// updateMixed converte: updateMixed(i, 'amount', parseMoney(maskedValue))
```

**Remover type="number" dos inputs com mascara** — substituir por `type="text"` com `inputMode` adequado para evitar conflito entre mascara e comportamento nativo do browser.
