## Story
**As a** operador do DistriAll,
**I want** ver o progresso do pedido como um stepper visual (lancado → confirmado → carregado → entregue),
**so that** eu veja de forma clara em que etapa o pedido esta.

## Acceptance Criteria

1. Stepper horizontal com 4 passos sequenciais: lancado → confirmado → carregado → entregue. O status `cancelado` NAO entra no fluxo linear do stepper — e tratado pelo AC 3.
2. Passo atual e todos os anteriores exibidos com `var(--accent)` (laranja preenchido); passos futuros em `var(--border-strong)` (cinza). Linha conectora entre passos segue a mesma logica: preenchida ate o passo atual, cinza apos.
3. Quando `order.status === 'cancelado'`, o stepper exibe todos os 4 passos em cinza com o label "Cancelado" em vermelho (`var(--danger-fg)`) abaixo do ultimo passo atingido antes do cancelamento — ou, se nenhum passo anterior for rastreavel, exibe o primeiro passo com indicador vermelho.
4. O stepper `<OrderStatusStepper>` e renderizado dentro de um `<Card>` logo abaixo do `<PageHeader>`, antes dos botoes de transicao. O badge `<OrderStatusBadge>` existente no `actions` do `PageHeader` e preservado sem alteracao.
5. O botao "Editar" nao aparece (ja controlado por `canEdit = status !== 'entregue' && status !== 'cancelado'` no page.tsx). Verificar que esta condicional continua correta apos a integracao do stepper — nenhuma mudanca de logica e necessaria, apenas confirmacao.

### Implementacao alvo (order-status-stepper.tsx)

```typescript
// apps/web/src/components/orders/order-status-stepper.tsx
'use client';
import { type OrderStatus, ORDER_STATUS_LABELS } from '@distriall/shared';

const FLOW: OrderStatus[] = ['lancado', 'confirmado', 'carregado', 'entregue'];

export function OrderStatusStepper({ status }: { status: OrderStatus }) {
  const idx = FLOW.indexOf(status);
  const isCancelled = status === 'cancelado';
  return (
    <div className="flex items-center gap-1.5 flex-wrap py-2">
      {FLOW.map((s, i) => (
        <React.Fragment key={s}>
          <div className="flex flex-col items-center gap-1">
            <span
              style={{
                width: 9, height: 9, borderRadius: '50%',
                background: !isCancelled && i <= idx ? 'var(--accent)' : 'var(--border-strong)',
                outline: !isCancelled && i === idx ? '3px solid var(--accent-soft-border)' : 'none',
              }}
            />
            <span className={`text-[10px] ${!isCancelled && i === idx ? 'text-foreground font-medium' : 'text-muted-foreground'}`}>
              {ORDER_STATUS_LABELS[s]}
            </span>
          </div>
          {i < FLOW.length - 1 && (
            <span style={{ width: 26, height: 2, borderRadius: 2, background: !isCancelled && i < idx ? 'var(--accent)' : 'var(--border-strong)', marginBottom: 14 }} />
          )}
        </React.Fragment>
      ))}
      {isCancelled && (
        <span className="text-[10px] text-destructive ml-2 font-medium">Cancelado</span>
      )}
    </div>
  );
}
```
