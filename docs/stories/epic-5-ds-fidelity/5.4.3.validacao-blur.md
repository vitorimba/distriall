## Story
**As a** operador do DistriAll,
**I want** que erros de validacao aparecam quando saio do campo ou submeto o form,
**so that** eu nao seja interrompido enquanto digito.

## Acceptance Criteria
1. Validacao dispara no blur do campo e no submit do form
2. Nunca validar a cada tecla (onChange)
3. Erro aparece via Field error prop (mensagem abaixo do campo)
4. Input com erro mostra borda vermelha (invalid state via `aria-invalid="true"` no elemento input/select; CSS do projeto ja trata `[aria-invalid=true]` com borda danger)
5. Mensagens canonicas de MSG (maskUtils): "Campo obrigatorio" (MSG.required), "Telefone incompleto" (MSG.phoneIncomplete)

**Imports necessarios:**
```ts
import { isPhoneComplete, MSG } from '@/lib/mask-utils'
import { Field } from '@/components/ui/field'
```

**Padrao de per-field error state (usar Record para forms com multiplos campos):**
```tsx
const [fieldErrors, setFieldErrors] = useState<Record<string, string>>({});

// Limpar erro ao comecar a digitar (opcional, melhora UX)
// Nao validar no onChange — apenas limpar erro anterior

// onBlur — validar campo individual
<Input
  value={name}
  onChange={(e) => { setName(e.target.value); }}
  onBlur={() => {
    if (!name.trim()) setFieldErrors(prev => ({ ...prev, name: MSG.required }));
    else setFieldErrors(prev => { const { name: _, ...rest } = prev; return rest; });
  }}
  aria-invalid={!!fieldErrors.name}
/>
<Field label="Nome" required error={fieldErrors.name}>
  {/* Input acima */}
</Field>
```

**Importante:** o `error` prop fica no `<Field>`, o `aria-invalid` fica no `<Input>` ou `<select>`. O CSS do projeto deve ter estilo para `[aria-invalid="true"]` com borda danger. Se nao tiver, adicionar `className={cn(fieldErrors.name && 'border-red-500')}` no Input.

**Padrao para telefone (combina com mascara de 5.4.2):**
```tsx
onBlur={() => {
  if (phone && !isPhoneComplete(phone)) {
    setFieldErrors(prev => ({ ...prev, phone: MSG.phoneIncomplete }));
  } else if (!phone) {
    // Telefone nao e obrigatorio no client-form — nao validar required
    setFieldErrors(prev => { const { phone: _, ...rest } = prev; return rest; });
  }
}}
```

**Padrao de validacao no submit (complementar ao blur):**
```tsx
async function handleSubmit(e: React.FormEvent) {
  e.preventDefault();
  // Re-validar todos os campos required no submit
  const newErrors: Record<string, string> = {};
  if (!name.trim()) newErrors.name = MSG.required;
  if (phone && !isPhoneComplete(phone)) newErrors.phone = MSG.phoneIncomplete;
  if (Object.keys(newErrors).length > 0) {
    setFieldErrors(newErrors);
    return;
  }
  // ... submit normal
}
```
