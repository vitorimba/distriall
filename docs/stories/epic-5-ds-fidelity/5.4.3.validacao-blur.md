# Story 5.4.3: Validacao no blur e submit, nunca a cada tecla

## Status
Draft

## Story
**As a** operador do DistriAll,
**I want** que erros de validacao aparecam quando saio do campo ou submeto o form,
**so that** eu nao seja interrompido enquanto digito.

## Acceptance Criteria
1. Validacao dispara no blur do campo e no submit do form
2. Nunca validar a cada tecla (onChange)
3. Erro aparece via Field error prop (mensagem abaixo do campo)
4. Input com erro mostra borda vermelha (invalid state)
5. Mensagens canonicas de MSG (maskUtils): "Campo obrigatorio", "Telefone incompleto"

## Tasks / Subtasks
- [ ] Task 1: client-form — validacao blur (nome required, telefone incompleto)
- [ ] Task 2: product-form — validacao blur (nome required, preco > 0)
- [ ] Task 3: expense-form — validacao blur (descricao required, valor > 0)
- [ ] Task 4: order new — validacao submit (cliente selecionado, itens > 0)
