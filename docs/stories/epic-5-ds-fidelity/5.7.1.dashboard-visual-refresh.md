## Story
**As a** dono/gestor do distribuidor,
**I want** que o dashboard tenha mais presenca visual (fonte maior, cards preenchidos, sidebar organizada),
**so that** a tela transmita autoridade e nao pareca "magra"/vazia como estava.

## Contexto
Story formalizada retroativamente. Origem: comparacao lado-a-lado do dashboard DistriAll
com outros sistemas do mesmo autor (BM PRO, Instituto Lemos), na qual o DistriAll foi
percebido como "magrinho" — cards ocos (sem icone nem 3a linha), tipografia leve, sidebar
chapada e header vazio. Este story eleva o craft usando **somente tokens ja existentes no
DESIGN.md** (Artigo IV — No Invention).

## Acceptance Criteria
1. Cada StatsCard do dashboard exibe icone colorido em badge soft (var(--chart-1..5)) + uma
   3a linha de contexto (subtitle), alem de titulo e valor.
2. StatsCard ganha nova prop `iconColor` (default var(--chart-1)); badge do icone usa
   color-mix 14% do token; card `accent` usa badge branco translucido.
3. Cards com elevacao via token: `--shadow-card` (normal) e `--shadow-accent` (hero laranja).
4. Tipografia aumentada, sempre via token do DS:
   - Valor do KPI: var(--text-stat) 28px → var(--text-display) 34px.
   - Titulo da pagina (PageHeader h1): text-lg 18px → var(--text-2xl) 25px.
   - Subtitulo da pagina: text-sm → var(--text-base) 15px.
   - Titulo do card: text-sm → text-base; subtitle do card: text-xs → text-sm.
   - Itens da sidebar: text-sm → text-base; overlines: 11px → var(--text-xs) 12px.
5. Sidebar agrupada em secoes com overline (Principal / Operacional / Financeiro / Sistema);
   largura md:w-56 → md:w-60.
6. Header exibe perfil com Avatar (iniciais) + nome + cargo (ROLE_LABELS pt-BR), no lugar do
   nome solto.
7. BarChart: barras pequenas continuam visiveis (minHeight 2px → 8px; opacidade nao-max
   0.5 → 0.7) — resolve o grafico "Evolucao semanal" com espaco morto.
8. Nenhum token novo inventado; lint e typecheck passam.
