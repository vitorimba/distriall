## Story
**As a** usuario do DistriAll,
**I want** ver mensagens de erro claras com botao de retry quando algo falha,
**so that** eu saiba o que deu errado e possa tentar novamente sem recarregar a pagina.

## Acceptance Criteria
1. Todo fetch que falha mostra `<Alert tone="danger">Nao foi possivel carregar {entidade}</Alert>`
2. Alert tem action com `<Button variant="outline" size="sm">Tentar novamente</Button>` com icon `refresh-cw`
3. Clicar em "Tentar novamente" refaz o fetch
4. Nunca mostrar codigo de erro cru, stack trace ou mensagem tecnica
5. Nomear o que falhou: "pedidos", "clientes", "produtos" (nunca generico "dados")
