### Refactoring Performed

- **File**: `apps/web/src/components/layout/bottom-nav.tsx`
  - **Change**: Token de cor ativa trocado de `var(--accent)` para `var(--accent-fg)` na linha 37
  - **Why**: `var(--accent)` mapeia para superficie muted (#F0EDE8 no light, #1D1D21 no dark) — ficaria invisivel sobre bg-background. DS CLAUDE.md regra 1: "Texto/icone accent usa --accent-fg"
  - **How**: Cor ativa agora renderiza laranja brand (#FB923C light / #E2640D dark) conforme DS

- **File**: `apps/web/src/hooks/use-theme.ts`
  - **Change**: Substituido setTheme() dentro de useEffect por lazy initializer `useState(getInitialTheme)` + useEffect apenas para applyTheme(theme)
  - **Why**: setTheme() chamado sincronamente dentro de useEffect causa cascading render (lint error react-hooks/set-state-in-effect introduzido em Story 5.5.6). Esta hook e importada por /more page desta story.
  - **How**: Elimina dupla renderizacao inicial, corrige lint error, mantendo comportamento identico. SSR-safe via guard `typeof window === 'undefined'`.
