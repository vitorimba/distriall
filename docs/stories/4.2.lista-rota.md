## Story
**As a** Tiago (admin),
**I want** montar a sequencia de entregas do dia para o Joao definindo a ordem dos clientes,
**so that** ele saiba a rota e nao se perca durante as entregas.

## Acceptance Criteria
1. Tela "Montar Rota" com pedidos carregados do dia (status "carregado") de todas as contas
2. Drag-and-drop OU numeracao manual para definir sequencia de entrega
3. Cada item mostra: nome do cliente, endereco, bairro/cidade, forma de pagamento
4. Botao "Enviar para Entregador" que cria o registro em `deliveries` e torna a rota visivel na tela do Joao
5. Link para Google Maps com a sequencia de enderecos (nice-to-have, opcional para v1)
6. Possibilidade de editar a rota (reordenar, adicionar/remover pedidos) enquanto delivery status for "pendente"

## Dev Notes

### Database Schema

Tabela `deliveries`:

```sql
CREATE TABLE public.deliveries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  account_id UUID NOT NULL REFERENCES public.accounts(id) ON DELETE CASCADE,
  driver_id UUID NOT NULL REFERENCES public.users(id),
  delivery_date DATE NOT NULL,
  status TEXT NOT NULL DEFAULT 'pendente'
    CHECK (status IN ('pendente', 'em_rota', 'concluida')),
  notes TEXT,
  started_at TIMESTAMPTZ,
  completed_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_deliveries_account ON public.deliveries(account_id);
CREATE INDEX idx_deliveries_driver ON public.deliveries(driver_id);
CREATE INDEX idx_deliveries_date ON public.deliveries(delivery_date);
```

Tabela `delivery_items`:

```sql
CREATE TABLE public.delivery_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  delivery_id UUID NOT NULL REFERENCES public.deliveries(id) ON DELETE CASCADE,
  order_id UUID NOT NULL REFERENCES public.orders(id),
  sequence INTEGER NOT NULL,
  status TEXT NOT NULL DEFAULT 'pendente'
    CHECK (status IN ('pendente', 'entregue', 'nao_entregue')),
  observation TEXT,
  delivered_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE(delivery_id, order_id)
);

CREATE INDEX idx_delivery_items_delivery ON public.delivery_items(delivery_id);
CREATE INDEX idx_delivery_items_order ON public.delivery_items(order_id);
```

### RLS Policies

```sql
-- Deliveries: admin/vendedor see all in account, entregador sees own
CREATE POLICY "View deliveries"
  ON public.deliveries FOR SELECT
  USING (
    (get_user_role_in_account(account_id) IN ('admin', 'vendedor'))
    OR (driver_id = auth.uid())
  );

-- Only admin can create/manage deliveries
CREATE POLICY "Admin creates deliveries"
  ON public.deliveries FOR INSERT
  WITH CHECK (
    account_id = ANY(get_user_account_ids())
    AND get_user_role_in_account(account_id) = 'admin'
  );

CREATE POLICY "Admin or driver updates deliveries"
  ON public.deliveries FOR UPDATE
  USING (
    driver_id = auth.uid()
    OR get_user_role_in_account(account_id) = 'admin'
  );

-- delivery_items: follow parent delivery access
CREATE POLICY "View delivery items"
  ON public.delivery_items FOR SELECT
  USING (
    delivery_id IN (
      SELECT id FROM deliveries
      WHERE get_user_role_in_account(account_id) IN ('admin', 'vendedor')
         OR driver_id = auth.uid()
    )
  );

CREATE POLICY "Admin manages delivery items"
  ON public.delivery_items FOR INSERT
  WITH CHECK (
    delivery_id IN (
      SELECT id FROM deliveries
      WHERE get_user_role_in_account(account_id) = 'admin'
    )
  );

CREATE POLICY "Admin or driver updates delivery items"
  ON public.delivery_items FOR UPDATE
  USING (
    delivery_id IN (
      SELECT id FROM deliveries
      WHERE driver_id = auth.uid()
         OR get_user_role_in_account(account_id) = 'admin'
    )
  );
```

// Gerar URL com waypoints
function buildGoogleMapsUrl(addresses: string[]): string {
  const encoded = addresses.map(a => encodeURIComponent(a));

### Fluxo Completo

1. Tiago abre "Montar Rota", seleciona data de hoje e entregador Joao
2. Sistema mostra pedidos com status "carregado" disponiveis
3. Tiago arrasta pedidos para a area da rota na ordem desejada
4. Tiago clica "Enviar para Entregador"
5. Sistema cria `delivery` + `delivery_items` com sequencia
6. Joao ve a rota na sua tela simplificada (Story 4.1)
7. Conforme Joao entrega, o status atualiza em realtime para o Tiago

### Nota sobre Multi-Conta

Uma rota pode conter pedidos de DIFERENTES contas (Distrial RP + Tiago + Votoporanga). A `delivery` e vinculada a uma conta (a conta principal do admin), mas os `delivery_items` podem referenciar orders de qualquer conta que o admin tenha acesso. Isso e importante porque o Joao entrega pedidos de todas as contas em uma unica viagem.
