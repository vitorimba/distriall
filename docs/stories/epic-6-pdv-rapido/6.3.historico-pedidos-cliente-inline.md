## Story
**As a** vendedor (Tiago ou Diego),
**I want** ver os ultimos pedidos do cliente selecionado diretamente na tela de novo pedido,
**so that** eu saiba rapidamente o que ele costuma comprar e consiga repetir ou ajustar pedidos anteriores sem precisar sair da tela.

## Scope

### IN
- Secao "Ultimos Pedidos" visivel na tela de novo pedido, apos selecionar o cliente
- Exibe os ultimos 5 pedidos do cliente (data, status, total, itens resumidos)
- Card expansivel: toque no pedido mostra itens com quantidades e precos
- Botao "Repetir pedido" que carrega todos os itens daquele pedido no carrinho atual
- Ao repetir, respeita precos customizados atuais do cliente (priceMap), nao os precos historicos
- Colapsavel para nao ocupar espaco quando o vendedor nao precisa

### OUT
- Historico completo com filtros e paginacao (ja existe na pagina do cliente, Story 4.4)
- Comparativo entre pedidos
- Sugestao automatica de produtos baseada em historico (futuro/IA)
- Merge de itens do pedido repetido com itens ja no carrinho (repetir substitui o carrinho, com confirmacao se ja tem itens)

## Dependencies
- **Story 6.1** (Catalogo Visual) — independente, podem ser implementadas em paralelo
- **Story 2.1** (Lancamento Pedidos) — COMPLETED. Cart store, pagina novo pedido
- **Story 4.4** (Historico Clientes) — COMPLETED. Hook use-client-orders ja existe, pode ser reutilizado

## Complexity
- **Estimate:** M (Medium)
- **Points:** 5
- **Rationale:** Novo componente de historico inline. Reutiliza hook use-client-orders existente (com limit 5). Logica de "repetir pedido" precisa buscar order_items e popular o cart store. Sem mudancas no backend.

## Risks
- **R1:** "Repetir pedido" com carrinho ja preenchido pode confundir o vendedor. **Mitigacao:** Confirmacao "Substituir itens atuais?" se carrinho nao estiver vazio.
- **R2:** Precos do pedido historico podem diferir dos precos atuais. **Mitigacao:** Ao repetir, usar precos atuais (priceMap do cliente), nao historicos. Exibir aviso se houver diferenca.
- **R3:** Secao pode ocupar muito espaco vertical na tela mobile. **Mitigacao:** Colapsavel, inicia fechado em mobile e aberto em desktop.

## Acceptance Criteria

1. **Given** cliente selecionado na tela de novo pedido, **When** pagina carrega, **Then** secao "Ultimos Pedidos" aparece mostrando ate 5 pedidos mais recentes (data, total, qtd de itens)
2. **Given** secao de historico visivel, **When** vendedor toca em um pedido, **Then** card expande mostrando lista de itens (produto, variante, quantidade, preco unitario na epoca)
3. **Given** pedido expandido no historico, **When** vendedor toca em "Repetir pedido", **Then** todos os itens daquele pedido sao carregados no carrinho com precos atuais do cliente
4. **Given** carrinho ja tem itens, **When** vendedor toca "Repetir pedido", **Then** dialogo de confirmacao pergunta "Substituir itens atuais?" antes de limpar e carregar
5. **Given** cliente sem pedidos anteriores, **When** pagina carrega, **Then** secao de historico nao aparece (sem mensagem "nenhum pedido" desnecessaria)
6. **Given** secao de historico visivel, **When** vendedor toca no header da secao, **Then** secao colapsa/expande (toggle)
7. **Given** pedido repetido carregado no carrinho, **When** algum produto do pedido antigo nao existe mais (inativo), **Then** produto e ignorado silenciosamente e mensagem discreta informa "X produto(s) removido(s) por estarem inativos"

### Logica de "Repetir Pedido"
```typescript
async function repeatOrder(orderId: string) {
  const order = await getOrder(orderId);
  const { priceMap, clearCart, addItem } = useCartStore.getState();
  
  // Verificar produtos ativos
  const activeProducts = await checkActiveProducts(order.items.map(i => i.variant_id));
  const skipped = order.items.filter(i => !activeProducts.has(i.variant_id));
  
  clearCart(); // mantém o cliente selecionado
  
  for (const item of order.items) {
    if (!activeProducts.has(item.variant_id)) continue;
    addItem({
      variantId: item.variant_id,
      productName: item.product_name,
      variantName: item.variant_name,
      quantity: item.quantity,
      costPrice: item.cost_price,
      defaultPrice: item.unit_price, // priceMap vai sobrescrever se tiver customizado
    });
  }
  
  if (skipped.length > 0) {
    toast(`${skipped.length} produto(s) removido(s) (inativos)`, 'warning');
  }
}
```
