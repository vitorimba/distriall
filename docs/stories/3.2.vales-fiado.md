## Story
**As a** Tiago (admin),
**I want** registrar vales assinados com foto e acompanhar o status de pagamento, alem de controlar o fiado de cada cliente,
**so that** eu nao precise ficar entrando no banco manualmente pra conferir quem pagou e quem deve.

## Acceptance Criteria
1. Ao marcar pagamento como "Vale", permitir upload de foto do vale assinado (armazenada no Supabase Storage bucket `voucher-photos`)
2. Vale com status: pendente, pago, vencido — com transicoes controladas
3. Tela "Vales Pendentes" com lista de vales aguardando pagamento, ordenados por data de vencimento
4. Marcar vale como "Pago" com data do pagamento registrada
5. Controle de fiado: saldo devedor por cliente (soma de vales pendentes + pedidos com pagamento pendente)
6. Historico de fiado por cliente com timeline de debitos e pagamentos
7. Fotos de vales acessiveis apenas por usuarios com acesso a conta (Storage RLS)

## Dev Notes

### Database Schema

Tabela `vouchers`:

```sql
CREATE TABLE public.vouchers (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  account_id UUID NOT NULL REFERENCES public.accounts(id) ON DELETE CASCADE,
  payment_id UUID NOT NULL REFERENCES public.payments(id) ON DELETE CASCADE,
  client_id UUID NOT NULL REFERENCES public.clients(id),
  amount NUMERIC(12,2) NOT NULL,
  status TEXT NOT NULL DEFAULT 'pendente'
    CHECK (status IN ('pendente', 'pago', 'vencido', 'cancelado')),
  photo_url TEXT, -- Supabase Storage path: voucher-photos/{account_id}/{voucher_id}.jpg
  due_date DATE,
  paid_at TIMESTAMPTZ,
  notes TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_vouchers_account ON public.vouchers(account_id);
CREATE INDEX idx_vouchers_client ON public.vouchers(client_id);
CREATE INDEX idx_vouchers_status ON public.vouchers(account_id, status);
CREATE INDEX idx_vouchers_payment ON public.vouchers(payment_id);
```

### Storage RLS

```sql
-- Bucket: voucher-photos
-- File path convention: voucher-photos/{account_id}/{voucher_id}.jpg

CREATE POLICY "Account members can view voucher photos"
  ON storage.objects FOR SELECT
  USING (
    bucket_id = 'voucher-photos'
    AND (storage.foldername(name))[1]::uuid = ANY(get_user_account_ids())
  );

CREATE POLICY "Account members can upload voucher photos"
  ON storage.objects FOR INSERT
  WITH CHECK (
    bucket_id = 'voucher-photos'
    AND (storage.foldername(name))[1]::uuid = ANY(get_user_account_ids())
  );
```

### RLS Policies para vouchers

```sql
CREATE POLICY "Users can view own account vouchers"
  ON public.vouchers FOR SELECT
  USING (account_id = ANY(get_user_account_ids()));

CREATE POLICY "Users can create vouchers in own accounts"
  ON public.vouchers FOR INSERT
  WITH CHECK (
    account_id = ANY(get_user_account_ids())
    AND get_user_role_in_account(account_id) IN ('admin', 'vendedor')
  );

CREATE POLICY "Users can update vouchers in own accounts"
  ON public.vouchers FOR UPDATE
  USING (account_id = ANY(get_user_account_ids()))
  WITH CHECK (get_user_role_in_account(account_id) IN ('admin', 'vendedor'));

CREATE POLICY "Admins can delete vouchers"
  ON public.vouchers FOR DELETE
  USING (
    account_id = ANY(get_user_account_ids())
    AND get_user_role_in_account(account_id) = 'admin'
  );
```

### Logica de Negocio

- **Criacao do vale:** Quando um pagamento com `method = 'vale'` e criado (Story 3.1), criar automaticamente um registro em `vouchers` vinculado ao `payment_id` e ao `client_id` do pedido
- **Upload de foto:** Opcional mas recomendado. Foto comprimida client-side (canvas resize) antes de enviar ao Supabase Storage. Path: `voucher-photos/{account_id}/{voucher_id}.jpg`
- **Vencimento automatico:** Considerar criar um cron job (Supabase Edge Function ou pg_cron) para marcar vales como `vencido` quando `due_date < CURRENT_DATE AND status = 'pendente'`. Alternativa mais simples: marcar como vencido no client-side ao renderizar
- **Saldo devedor:** Query para calcular:

```sql
-- Saldo devedor de um cliente
SELECT
  c.id,
  c.name,
  COALESCE(SUM(v.amount) FILTER (WHERE v.status = 'pendente'), 0) as vouchers_pendentes,
  COALESCE(SUM(p.amount) FILTER (WHERE p.status = 'pendente' AND p.method != 'vale'), 0) as pagamentos_pendentes,
  COALESCE(SUM(v.amount) FILTER (WHERE v.status = 'pendente'), 0) +
  COALESCE(SUM(p.amount) FILTER (WHERE p.status = 'pendente' AND p.method != 'vale'), 0) as saldo_devedor
FROM clients c
LEFT JOIN vouchers v ON v.client_id = c.id
LEFT JOIN payments p ON p.order_id IN (SELECT id FROM orders WHERE client_id = c.id)
WHERE c.id = $1 AND c.account_id = $2
GROUP BY c.id, c.name;
```
