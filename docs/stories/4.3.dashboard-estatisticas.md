## Dev Notes

### API Route: GET /api/stats

```typescript
// apps/web/src/app/api/stats/route.ts
// Query params: account_id?, period, start_date?, end_date?

// Response type:
interface StatsResponse {
  revenue: number;           // total vendido
  cost: number;              // custo das mercadorias
  profit: number;            // revenue - cost
  order_count: number;       // total de pedidos
  client_count: number;      // clientes unicos atendidos
  avg_ticket: number;        // revenue / order_count

  payment_breakdown: {
    method: string;          // 'dinheiro' | 'pix' | 'boleto' | 'vale' | 'cartao'
    amount: number;
    percentage: number;      // 0-100
  }[];

  product_ranking: {
    product_name: string;
    variant_name: string;
    total_value: number;     // SUM(order_items.total)
    total_quantity: number;  // SUM(order_items.quantity)
  }[];

  weekly_evolution: {
    week: string;            // '2026-W23' or 'Jun 02-08'
    revenue: number;
    profit: number;
  }[];
}
```

### SQL Queries para Stats

**Metricas basicas:**

```sql
SELECT
  COALESCE(SUM(o.total), 0) as revenue,
  COALESCE(SUM(o.total_cost), 0) as cost,
  COALESCE(SUM(o.profit), 0) as profit,
  COUNT(*) as order_count,
  COUNT(DISTINCT o.client_id) as client_count,
  CASE WHEN COUNT(*) > 0 THEN COALESCE(SUM(o.total), 0) / COUNT(*) ELSE 0 END as avg_ticket
FROM orders o
WHERE o.account_id = ANY($1)  -- array de accounts (ou todas do usuario)
  AND o.created_at::date BETWEEN $2 AND $3
  AND o.status != 'cancelado';
```

**Breakdown por forma de pagamento:**

```sql
SELECT
  p.method,
  SUM(p.amount) as amount,
  ROUND(SUM(p.amount) * 100.0 / NULLIF(SUM(SUM(p.amount)) OVER(), 0), 1) as percentage
FROM payments p
JOIN orders o ON p.order_id = o.id
WHERE o.account_id = ANY($1)
  AND o.created_at::date BETWEEN $2 AND $3
  AND o.status != 'cancelado'
  AND p.status != 'cancelado'
GROUP BY p.method
ORDER BY amount DESC;
```

**Ranking de produtos (por valor):**

```sql
SELECT
  oi.product_name,
  oi.variant_name,
  SUM(oi.total) as total_value,
  SUM(oi.quantity) as total_quantity
FROM order_items oi
JOIN orders o ON oi.order_id = o.id
WHERE o.account_id = ANY($1)
  AND o.created_at::date BETWEEN $2 AND $3
  AND o.status != 'cancelado'
  AND oi.is_returned = false
GROUP BY oi.product_name, oi.variant_name
ORDER BY total_value DESC
LIMIT 10;
```

**Evolucao semanal (ultimas 12 semanas):**

```sql
SELECT
  DATE_TRUNC('week', o.created_at) as week,
  SUM(o.total) as revenue,
  SUM(o.profit) as profit
FROM orders o
WHERE o.account_id = ANY($1)
  AND o.created_at >= CURRENT_DATE - INTERVAL '12 weeks'
  AND o.status != 'cancelado'
GROUP BY DATE_TRUNC('week', o.created_at)
ORDER BY week ASC;
```

### Formatacao de Moeda

```typescript
// packages/shared/src/utils/currency.ts
export function formatCurrency(value: number): string {
  return new Intl.NumberFormat('pt-BR', {
    style: 'currency',
    currency: 'BRL',
  }).format(value);
}

// formatCurrency(993.50) => "R$ 993,50"
// formatCurrency(15420.00) => "R$ 15.420,00"
```
