## Story
**As a** Tiago,
**I want** cadastrar meus clientes com endereco, forma de pagamento padrao e precos especificos por produto,
**so that** na hora do pedido os precos ja venham corretos para cada cliente.

## Acceptance Criteria
1. CRUD completo de clientes vinculado a conta ativa (admin e vendedor podem criar/editar)
2. Campos do cliente: nome, nome fantasia (trade_name), endereco, cidade, bairro, telefone, whatsapp, forma_pagamento_padrao, notas
3. Tabela `client_prices` com: client_id, product_variant_id, custom_price — override do preco padrao
4. Ao criar pedido e selecionar cliente, precos customizados sao aplicados automaticamente (logica de fallback: custom_price ?? sell_price)
5. Se nao houver preco customizado para um produto/variacao, usa o preco padrao do `product_variants.sell_price`
6. Cliente pode existir em mais de uma conta com precos diferentes (registros separados por account_id)
7. Lista de clientes com busca por nome
8. Tela de detalhe do cliente com aba de precos especiais (gerenciar overrides)
9. Soft delete: cliente desativado (is_active=false) nao aparece em novas operacoes

## Dev Notes

### Schema SQL — Tabela `clients`
```sql
CREATE TABLE public.clients (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  account_id UUID NOT NULL REFERENCES public.accounts(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  trade_name TEXT,              -- nome fantasia
  address TEXT,
  city TEXT,
  neighborhood TEXT,            -- bairro
  phone TEXT,
  whatsapp TEXT,
  default_payment_method TEXT CHECK (default_payment_method IN ('dinheiro', 'pix', 'boleto', 'vale', 'cartao')),
  notes TEXT,
  is_active BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_clients_account ON public.clients(account_id);
CREATE INDEX idx_clients_name ON public.clients(account_id, name);
```

### Schema SQL — Tabela `client_prices`
```sql
CREATE TABLE public.client_prices (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  account_id UUID NOT NULL REFERENCES public.accounts(id) ON DELETE CASCADE,
  client_id UUID NOT NULL REFERENCES public.clients(id) ON DELETE CASCADE,
  product_variant_id UUID NOT NULL REFERENCES public.product_variants(id) ON DELETE CASCADE,
  custom_price NUMERIC(10,2) NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),

  UNIQUE(client_id, product_variant_id)
);

CREATE INDEX idx_client_prices_client ON public.client_prices(client_id);
CREATE INDEX idx_client_prices_account ON public.client_prices(account_id);
```

### RLS Policies — `clients` (mesmo padrao para `client_prices`)
```sql
ALTER TABLE public.clients ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.client_prices ENABLE ROW LEVEL SECURITY;

-- SELECT
CREATE POLICY "Users can view own account clients"
  ON public.clients FOR SELECT
  USING (account_id = ANY(get_user_account_ids()));

-- INSERT
CREATE POLICY "Users can create clients in own accounts"
  ON public.clients FOR INSERT
  WITH CHECK (
    account_id = ANY(get_user_account_ids())
    AND get_user_role_in_account(account_id) IN ('admin', 'vendedor')
  );

-- UPDATE
CREATE POLICY "Users can update clients in own accounts"
  ON public.clients FOR UPDATE
  USING (account_id = ANY(get_user_account_ids()))
  WITH CHECK (get_user_role_in_account(account_id) IN ('admin', 'vendedor'));

-- DELETE
CREATE POLICY "Admins can delete clients"
  ON public.clients FOR DELETE
  USING (
    account_id = ANY(get_user_account_ids())
    AND get_user_role_in_account(account_id) = 'admin'
  );
```

### Query — Resolver precos para um cliente
```sql
-- Retorna todos os produtos/variacoes com preco efetivo para o cliente
SELECT
  pv.id AS variant_id,
  p.name AS product_name,
  pv.name AS variant_name,
  pv.sell_price AS default_price,
  cp.custom_price,
  COALESCE(cp.custom_price, pv.sell_price) AS effective_price,
  pv.cost_price
FROM public.product_variants pv
JOIN public.products p ON p.id = pv.product_id
LEFT JOIN public.client_prices cp ON cp.product_variant_id = pv.id AND cp.client_id = '<client_id>'
WHERE pv.account_id = '<account_id>'
  AND pv.is_active = true
  AND p.is_active = true
ORDER BY p.name, pv.weight_grams;
```
