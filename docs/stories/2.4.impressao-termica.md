## Risks
- **R1:** Impressora do Tiago pode usar UUIDs nao-padrao. **Mitigacao:** Fallback com `acceptAllDevices` + lista de UUIDs conhecidos.
- **R2:** Web Bluetooth requer HTTPS e gesto do usuario. **Mitigacao:** Vercel garante HTTPS; primeiro connect via botao explicito.
- **R3:** Encoding de acentos pode falhar em impressoras genericas. **Mitigacao:** Tentar CP860, fallback para strip accents.
- **R4:** BLE buffer overflow com cupons grandes. **Mitigacao:** Chunking de 512 bytes com delay 50ms entre chunks.

## Dev Notes

### Web Bluetooth API - Pontos Criticos

A Web Bluetooth API funciona APENAS em:
- Android Chrome 56+ (todos os usuarios alvo)
- Windows Chrome/Edge (Diego desktop)
- NAO funciona em iOS Safari (irrelevante - nenhum usuario usa iOS)

**Requisitos:**
- Pagina servida via HTTPS (Vercel ja garante)
- Primeiro pareamento exige gesto do usuario (tap no botao)
- Device picker nativo do browser aparece automaticamente

### ESC/POS Builder (Architecture Doc Secao 8.3)

Implementar exatamente conforme o architecture doc. Comandos-chave:
- `0x1B 0x40` = ESC @ (init)
- `0x1B 0x61 n` = ESC a (align: 0=left, 1=center, 2=right)
- `0x1B 0x45 n` = ESC E (bold: 0=off, 1=on)
- `0x1D 0x21 n` = GS ! (double size: 0x11=on, 0x00=off)
- `0x0A` = LF (newline)
- `0x1D 0x56 0x00` = GS V (full cut)

Largura de impressao 58mm = 32 caracteres por linha em fonte normal.

### BLE Chunking

BLE tem limite de ~512 bytes por write. O print manager deve:
1. Dividir o buffer em chunks de 512 bytes
2. Enviar cada chunk com `writeValueWithResponse`
3. Delay de 50ms entre chunks para nao estourar buffer da impressora

```typescript
const CHUNK_SIZE = 512;
for (let i = 0; i < data.length; i += CHUNK_SIZE) {
  const chunk = data.slice(i, i + CHUNK_SIZE);
  await characteristic.writeValueWithResponse(chunk);
  await new Promise(resolve => setTimeout(resolve, 50));
}
```

### Encoding de Acentos

Impressoras ESC/POS usam code pages, nao UTF-8. Opcoes:
1. **CP860** (Portuguese): suporta acentos pt-BR nativamente. Comando: `0x1B 0x74 0x03`
2. **Strip accents**: remover acentos (ex: "Opcao" -> "Opcao"). Mais simples, menos elegante.

Recomendacao: tentar CP860 primeiro; se impressora nao suportar, usar strip accents como fallback.

### Known Limitations (Architecture Doc Secao 8.9)

- Impressoras Bluetooth Classic (nao BLE) NAO funcionam com Web Bluetooth
- Primeiro pareamento requer gesto do usuario (seguranca do browser)
- Sem impressao em background (app deve estar aberto)
- Alguns modelos chineses baratos usam UUIDs nao-padrao (fallback com `acceptAllDevices`)
