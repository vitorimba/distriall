## Story
**As a** Tiago (admin),
**I want** imprimir ou copiar a rota montada como uma lista formatada (sequencia, cliente, endereco, forma de pagamento),
**so that** eu pare de reescrever a rota no papel todo dia e entregue uma lista impressa pro Joao junto com os boletos e recibos.

## Contexto (fala do Tiago)
> "eu faco uma rota tambem, um papel, todos os dias eu coloco o nome do cliente, o endereco do cliente, a forma de pagamento dele, e ai eu coloco, tipo assim, o primeiro, segundo, terceiro, a media ai e de 15 a 20 clientes ai por dia"
> "o Diego pega essa lista, pega os boletos, pega as notinhas dos pedidos tudo impresso e leva o carro ate o entregador"

## Problema
A Story 4.2 (Lista de Rota) esta DONE — o Tiago monta a rota no app com drag-and-drop e envia para o entregador. Mas **nao existe botao para imprimir ou copiar a rota**, entao ele reescreve tudo em papel manualmente (15-20 clientes/dia, ~20-30 min).

## Scope

### IN
- Botao "Imprimir" na tela de rota montada (ao lado de "Enviar rota")
- Impressao formatada: lista numerada com cliente, endereco, forma de pagamento
- Botao "Copiar" que gera texto formatado para clipboard (para WhatsApp)
- CSS @media print para layout limpo de impressao
- Reusar infra de impressao termica existente (Story 2.4) se aplicavel

### OUT
- PDF export (impressao via browser e suficiente)
- Integracao com impressao de recibos/boletos na mesma folha

## Dependencies
- **Story 4.2** (Lista de Rota) — DONE
- **Story 2.4** (Impressao Termica) — DONE

## Complexity
- **Estimate:** S (Small)
- **Points:** 3
- **Rationale:** 2 botoes + funcao de formatacao de texto + CSS print. Sem migration, sem componente complexo. A tela ja existe, so falta o output.

## Acceptance Criteria
1. Botao "Imprimir" visivel na tela de rota montada, ao lado de "Enviar rota"
2. Ao clicar "Imprimir", abre dialog de impressao do browser com layout limpo:
   - Cabecalho: data, entregador, total de paradas
   - Lista numerada: # | Cliente | Endereco | Forma de Pagamento
   - Sem elementos de navegacao do app (sidebar, header)
3. Botao "Copiar" gera texto formatado no clipboard:
   ```
   Rota 23/08 - Joao (15 paradas)
   1. Cliente A - Rua X, 123 - PIX
   2. Cliente B - Rua Y, 456 - Dinheiro
   3. Cliente C - Rua Z, 789 - Boleto
   ```
4. Toast de confirmacao "Lista copiada!" ao copiar
5. Funciona em mobile (botoes acessiveis, texto copiavel)

## Risks
- **Compatibilidade CSS @media print em Safari/iOS:** Safari tem comportamento diferente para `window.print()` e `@media print`. Mitigacao: testar no Safari antes de fechar — a Story 2.6 (impressao iOS Safari) ja mapeou esse risco no projeto.
- **Clipboard API bloqueada em contextos nao-HTTPS:** `navigator.clipboard.writeText()` requer HTTPS. Em dev local (HTTP), pode falhar silenciosamente. Mitigacao: implementar fallback via `document.execCommand('copy')`.
