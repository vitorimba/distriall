## Story
**As a** Tiago,
**I want** cadastrar meus ~200 produtos com nome, peso, variacoes de tamanho, preco de custo e preco de venda,
**so that** eu tenha meu catalogo completo no sistema.

## Acceptance Criteria
1. CRUD completo de produtos vinculado a conta ativa (apenas admin e vendedor podem criar/editar)
2. Campos do produto: nome, descricao (opcional), categoria (opcional), unidade (un, kg, g, l)
3. Suporte a variacoes de tamanho no mesmo produto (ex: Creme de Cebola 500g, 1kg, 25kg como variacoes) — tabela `product_variants`
4. Cada variacao tem: nome (ex: "500g"), peso em gramas, preco de custo (NUMERIC 10,2), preco de venda (NUMERIC 10,2), SKU (opcional)
5. Lista de produtos com busca por nome e filtro por categoria
6. Edicao de precos em lote: selecionar N produtos/variacoes, atualizar preco de venda e/ou custo
7. Cada conta tem seu proprio catalogo com precos independentes (isolamento por account_id + RLS)
8. Soft delete: produto/variacao desativado (is_active=false) nao aparece em novas operacoes mas mantem historico

## Dev Notes

### Schema SQL — Tabela `products`
```sql
CREATE TABLE public.products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  account_id UUID NOT NULL REFERENCES public.accounts(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  description TEXT,
  category TEXT,          -- agrupamento opcional (ex: "temperos", "molhos", "carnes")
  unit TEXT NOT NULL DEFAULT 'un', -- 'un', 'kg', 'g', 'l'
  is_active BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_products_account ON public.products(account_id);
CREATE INDEX idx_products_name ON public.products(account_id, name);
```

### Schema SQL — Tabela `product_variants`
```sql
CREATE TABLE public.product_variants (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  product_id UUID NOT NULL REFERENCES public.products(id) ON DELETE CASCADE,
  account_id UUID NOT NULL REFERENCES public.accounts(id) ON DELETE CASCADE,
  name TEXT NOT NULL,             -- '500g', '1kg', '25kg'
  weight_grams INTEGER,           -- peso em gramas para sorting/calculo
  cost_price NUMERIC(10,2) NOT NULL,  -- preco de custo
  sell_price NUMERIC(10,2) NOT NULL,  -- preco de venda padrao
  sku TEXT,                        -- SKU opcional
  is_active BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_product_variants_product ON public.product_variants(product_id);
CREATE INDEX idx_product_variants_account ON public.product_variants(account_id);
```

### RLS Policies — `products` (mesmo padrao para `product_variants`)
```sql
ALTER TABLE public.products ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.product_variants ENABLE ROW LEVEL SECURITY;

-- SELECT: usuario ve produtos das contas que pertence
CREATE POLICY "Users can view own account products"
  ON public.products FOR SELECT
  USING (account_id = ANY(get_user_account_ids()));

-- INSERT: admin ou vendedor
CREATE POLICY "Users can create products in own accounts"
  ON public.products FOR INSERT
  WITH CHECK (
    account_id = ANY(get_user_account_ids())
    AND get_user_role_in_account(account_id) IN ('admin', 'vendedor')
  );

-- UPDATE: admin ou vendedor
CREATE POLICY "Users can update products in own accounts"
  ON public.products FOR UPDATE
  USING (account_id = ANY(get_user_account_ids()))
  WITH CHECK (get_user_role_in_account(account_id) IN ('admin', 'vendedor'));

-- DELETE: apenas admin
CREATE POLICY "Admins can delete products"
  ON public.products FOR DELETE
  USING (
    account_id = ANY(get_user_account_ids())
    AND get_user_role_in_account(account_id) = 'admin'
  );
```

### Validacao Zod
```typescript
import { z } from 'zod';

const productVariantSchema = z.object({
  name: z.string().min(1, 'Nome da variacao obrigatorio'),
  weight_grams: z.number().int().positive().optional(),
  cost_price: z.number().min(0, 'Preco de custo deve ser >= 0'),
  sell_price: z.number().min(0, 'Preco de venda deve ser >= 0'),
  sku: z.string().optional(),
});

const productSchema = z.object({
  name: z.string().min(1, 'Nome do produto obrigatorio'),
  description: z.string().optional(),
  category: z.string().optional(),
  unit: z.enum(['un', 'kg', 'g', 'l']),
  variants: z.array(productVariantSchema).min(1, 'Pelo menos 1 variacao obrigatoria'),
});
```
