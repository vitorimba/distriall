Tooltip por hover/foco para botões só-ícone e abreviações; rótulo curto, nunca frases.

```jsx
<Tooltip label="Editar cliente">
  <IconButton icon="pencil" label="Editar cliente" />
</Tooltip>
```

- `position="bottom"` quando o alvo está no topo da tela.
- Não usar para conteúdo essencial — tooltip é reforço, não única fonte.
