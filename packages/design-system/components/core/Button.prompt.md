Action button; `primary` (orange) is reserved for the single main action of a view.

```jsx
<Button icon="plus">Novo pedido</Button>
<Button variant="outline">Cancelar</Button>
```

Variants: `primary | secondary | outline | ghost | danger`. Props: `size` (sm/md/lg), `icon` (Lucide name), `loading`, `fullWidth`. Labels are sentence case pt-BR ("Salvar pedido", never "SALVAR PEDIDO").
