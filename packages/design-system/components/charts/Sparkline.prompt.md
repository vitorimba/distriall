Mini-tendência sem eixos para dentro de StatCards, células de tabela e cabeçalhos — contexto visual rápido, nunca leitura precisa.

```jsx
<Sparkline values={[3200, 4100, 3650, 5200, 6840]} />
```

- Use `color="var(--success)"` ou `var(--danger)` para reforçar direção.
- Não adicione tooltip nem rótulos — se precisar de leitura, use LineChart.
