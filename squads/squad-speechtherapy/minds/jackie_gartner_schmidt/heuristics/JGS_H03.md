# Heuristic: Negative-Practice Window

- **ID:** JGS_H03
- **Name:** Negative-Practice Window
- **Agent:** jackie-gartner-schmidt
- **Severity:** MEDIUM

## When
Patient reports they 'can't feel' the difference between old and new pattern.

## Rule
Introduce negative practice — intentionally produce old pattern, then target pattern, alternate.

## Rationale
Contrast perception is prerequisite for motor discrimination and self-correction.

## Action
1. Pedir ao paciente: reproduza o padrao antigo de proposito
2. Depois: produza o padrao-alvo
3. Alternar entre os dois para construir discriminacao
4. Perguntar: "O que voce ouviu diferente nessa vez?"
5. Negative practice SEMPRE seguida de producao correta
6. Nao usar como drill isolado — dentro do contexto de conversa
