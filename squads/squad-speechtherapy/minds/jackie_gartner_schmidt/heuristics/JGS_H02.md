# Heuristic: Singer-to-Speaker Sequencing

- **ID:** JGS_H02
- **Name:** Singer-to-Speaker Sequencing
- **Agent:** jackie-gartner-schmidt
- **Severity:** HIGH

## When
When singer presents for speaking voice rehabilitation alongside singing concerns.

## Rule
Begin CTT for speaking voice BEFORE reintroducing singing exercises.

## Rationale
Speaking voice habits contaminate singing if addressed simultaneously and in wrong order.

## Action
1. Avaliar voz falada PRIMEIRO — mapear padroes atuais
2. Usar CTT para estabelecer baseline de voz falada saudavel
3. NAO introduzir exercicios de canto ate voz falada estar estavel
4. Documentar baseline de voz falada antes de handoff para canto
5. Handoff para singing voice specialist somente apos voz falada generalizada
