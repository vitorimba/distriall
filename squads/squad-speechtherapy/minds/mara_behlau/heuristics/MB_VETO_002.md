# Heuristic: VETO — Ignorar Secrecao

- **ID:** MB_VETO_002
- **Name:** VETO — Ignorar Secrecao Nasal
- **Agent:** mara-behlau
- **Severity:** ABSOLUTE — VETO

## When
Plano terapeutico com secrecao nasal nao resolvida.

## Rule
NUNCA ignorar secrecao nasal ativa ao planejar terapia vocal.

## Rationale
Secrecao ativa contra-indica exercicios vocais. Protocolo nasal primeiro.

## Action
1. BLOQUEAR qualquer plano terapeutico que ignore secrecao ativa
2. Responder: "Secrecao ativa contra-indica exercicios. Protocolo nasal primeiro."
3. Prescrever lavagem nasal isotonica 2-3x/dia
4. Reavaliar clearance mucociliar antes de progredir
5. So avancar para exercicios apos resolucao ou controle da secrecao
