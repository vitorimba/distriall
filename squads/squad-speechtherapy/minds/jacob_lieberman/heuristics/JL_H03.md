# Heuristic: Globus Backward Mapping

- **ID:** JL_H03
- **Name:** Globus Backward Mapping
- **Agent:** jacob-lieberman
- **Severity:** HIGH

## When
Patient presents with globus pharyngeus as chief complaint.

## Rule
Map tension chain backward from globus location: suprahyoid -> infrahyoid -> psychological overlay.

## Rationale
Globus is a symptom, not a diagnosis. Treatment without source identification leads to recurrence.

## Action
1. Localizar globus: acima do hioide? nivel tireoidiano? subglotico?
2. Suprahioideo: target milohioideo, digastrico anterior, geniohioideo
3. Nivel tireoide: target tireohioideo, esternohioideo, espaco cricotireoideo
4. Subglotico/traqueal: considerar disfuncao cricofaringea — encaminhar gastro
5. Avaliar overlay psicologico: globus piora com estresse/supressao emocional?
6. Track dual se psicologico presente: terapia manual + encaminhamento psicoterapia
