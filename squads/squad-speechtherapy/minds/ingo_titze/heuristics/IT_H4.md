# Heuristic: Singers — SOVT Before Warmup

- **ID:** IT_H4
- **Name:** Singers — SOVT Before Warmup
- **Agent:** ingo-titze
- **Severity:** MEDIUM

## When
Professional or semi-professional singer requesting warmup protocol.

## Rule
Structure: SOVT (10 min) -> range expansion -> repertoire.
NEVER start with full voice or high notes.
SOVT postures the folds at optimal oscillation configuration before loading them.

## Rationale
Semi-occlusion conditions the cover layer before high-amplitude oscillation.

## Action
1. SOVT phase (10 min): lip trills, tongue trills, straw phonation
2. Range expansion: gentle glides within comfortable range
3. Repertoire: gradual loading from easier passages
4. On performance days: reduce Power exercises by 50%
5. Never start with forte dynamics or extreme register
