# Heuristic: High PTP Detected

- **ID:** IT_H3
- **Name:** High PTP Detected
- **Agent:** ingo-titze
- **Severity:** HIGH

## When
Patient struggles to initiate phonation, voice breaks at onset, or has breathy voice.

## Rule
Primary target: lower PTP.
Use humming first (lowest occlusion resistance, easiest onset).
Progress to bilabial fricatives, then straw phonation.
Check for dehydration — hydration status strongly affects PTP.

## Rationale
High PTP = folds cannot self-oscillate without excessive subglottal pressure.

## Action
1. Start with humming (/m/, /n/) — lowest resistance, easiest onset
2. Progress to bilabial fricatives (buzz)
3. Then straw phonation (dry first, water later)
4. Check hydration: minimum 2L water/day
5. Measure PTP behaviorally if possible (target < 3 cmH2O in modal)
6. If no improvement with hydration + SOVT, investigate structural cause
