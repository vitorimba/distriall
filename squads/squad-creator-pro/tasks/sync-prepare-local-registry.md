# Task: Sync Prepare Local Registry

| Field | Value |
|-------|-------|
| **Task ID** | sync-prepare-local-registry |
| **Version** | 1.0.0 |
| **Executor** | Worker |
| **Execution Type** | Deterministic |
| **Estimated Time** | 3 min (all projects) |

## Purpose

Escanear CADA projeto e registrar quais rules, hooks, commands e squads são LOCAIS
(existem no projeto mas NÃO no template). Salvar em `.aiox/local-registry.yaml`.

Sem registry → rsync com --delete mata artefatos locais.
Com registry → sync sabe o que preservar.

**Idempotente:** Regenera o registry inteiro a cada execução (source of truth atualizada).

## Inputs

| Parameter | Type | Required | Default |
|-----------|------|----------|---------|
| `projects_base` | string | Yes | `from .aiox/sync-config.yaml → projects_base` |
| `template_path` | string | Yes | `from .aiox/sync-config.yaml → template_path` |

## Steps

Para CADA projeto em projects_base (exceto aiox):

### 1. Coletar artefatos do template (referência)

```bash
TEMPLATE_RULES=$(ls "{template}/.claude/rules/" 2>/dev/null | sort)
TEMPLATE_HOOKS=$(ls "{template}/.claude/hooks/" 2>/dev/null | sort)
TEMPLATE_CMDS=$(ls -d "{template}/.claude/commands/"*/ 2>/dev/null | xargs -I{} basename {} | sort)
TEMPLATE_SQUADS=$(ls -d "{template}/squads/"*/ 2>/dev/null | xargs -I{} basename {} | sort)
```

### 2. Coletar artefatos do projeto

```bash
PROJECT_RULES=$(ls "{project}/.claude/rules/" 2>/dev/null | sort)
PROJECT_HOOKS=$(ls "{project}/.claude/hooks/" 2>/dev/null | sort)
PROJECT_CMDS=$(ls -d "{project}/.claude/commands/"*/ 2>/dev/null | xargs -I{} basename {} | sort)
PROJECT_SQUADS=$(ls -d "{project}/squads/"*/ 2>/dev/null | xargs -I{} basename {} | sort)
```

### 3. Calcular diff (local = projeto - template)

```bash
LOCAL_RULES=$(comm -23 <(echo "$PROJECT_RULES") <(echo "$TEMPLATE_RULES"))
LOCAL_HOOKS=$(comm -23 <(echo "$PROJECT_HOOKS") <(echo "$TEMPLATE_HOOKS"))
LOCAL_CMDS=$(comm -23 <(echo "$PROJECT_CMDS") <(echo "$TEMPLATE_CMDS"))
LOCAL_SQUADS=$(comm -23 <(echo "$PROJECT_SQUADS") <(echo "$TEMPLATE_SQUADS"))
```

### 4. Gerar local-registry.yaml no projeto

```yaml
# .aiox/local-registry.yaml
# Auto-generated by sync-prepare-local-registry
# Files listed here are LOCAL to this project and PRESERVED during sync
# Regenerated before each sync — do not edit manually

generated: "2026-04-14T..."
project: "{project_name}"
template_ref: "{template_path}"

local_artifacts:
  rules:
    - "custom-project-rule.md"
    # Files in .claude/rules/ that do NOT exist in template
  hooks:
    - "project-specific-hook.cjs"
    # Files in .claude/hooks/ that do NOT exist in template
  commands:
    - "project-custom-squad/"
    # Dirs in .claude/commands/ that do NOT exist in template
  squads:
    - "project-local-squad/"
    # Dirs in squads/ that do NOT exist in template

counts:
  local_rules: N
  local_hooks: N
  local_commands: N
  local_squads: N
  total_local: N
```

### 5. Salvar

```bash
mkdir -p "{project}/.aiox"
# Write YAML to .aiox/local-registry.yaml
```

## Como o sync-template-execute usa o registry

```bash
# Antes de rsync --delete em L2 (rules):
# Ler local-registry.yaml e gerar --exclude para cada local rule
for local_rule in $(parse_local_rules "{project}/.aiox/local-registry.yaml"); do
  EXCLUDES="$EXCLUDES --exclude=$local_rule"
done
rsync -av --delete $EXCLUDES {template}/.claude/rules/ {project}/.claude/rules/
```

Isso impossibilita que o rsync delete artefatos locais. Bloqueio físico.
