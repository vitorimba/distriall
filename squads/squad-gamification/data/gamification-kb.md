## 1. Definition & History

**Gamification** is the application of game-design elements and game principles in non-game contexts to improve user engagement, organizational productivity, learning, and other measurable outcomes.

**Key Distinction:** Gamification is NOT making something a game. It is using selected game elements strategically to enhance existing experiences.

## 2. Core Concepts

### Intrinsic vs Extrinsic Motivation
- **Intrinsic:** Doing something because it is inherently interesting or enjoyable (curiosity, mastery, purpose)
- **Extrinsic:** Doing something for an external reward or to avoid punishment (points, badges, money)
- **Overjustification Effect:** When extrinsic rewards undermine pre-existing intrinsic motivation (Deci & Ryan, 1985)
- **Design Goal:** Use extrinsic elements to bootstrap engagement, then transition to intrinsic drivers

### Self-Determination Theory (Deci & Ryan)
Three basic psychological needs:
1. **Autonomy** — Feeling of volition and choice
2. **Competence** — Feeling of effectiveness and mastery
3. **Relatedness** — Feeling of connection and belonging

### Flow State (Csikszentmihalyi)
Optimal experience occurs when:
- Challenge matches skill level
- Clear goals exist
- Immediate feedback provided
- Sense of control maintained
- Concentration is deep
- Time distortion occurs

### MDA Framework (Hunicke, LeBlanc, Zubek)
- **Mechanics:** Rules, components, data (what the designer builds)
- **Dynamics:** Run-time behavior of mechanics (what happens when played)
- **Aesthetics:** Emotional responses evoked (what the player feels)

## 3. Primary Frameworks

### 3.1 Octalysis (Yu-kai Chou)
8 Core Drives of human motivation:
1. **Epic Meaning & Calling** — Being part of something greater
2. **Development & Accomplishment** — Progress, achievement, mastery
3. **Empowerment of Creativity & Feedback** — Creative expression, feedback loops
4. **Ownership & Possession** — Collecting, customizing, investing
5. **Social Influence & Relatedness** — Mentorship, competition, social proof
6. **Scarcity & Impatience** — Wanting what you can't have (yet)
7. **Unpredictability & Curiosity** — Not knowing what happens next
8. **Loss & Avoidance** — Not wanting to lose what you have

**White Hat (1,2,3):** Empowering, sustainable, positive long-term
**Black Hat (6,7,8):** Urgent, compelling, potentially exploitative
**Left Brain (2,4,6):** Extrinsic tendencies (logic, ownership, rewards)
**Right Brain (3,5,7):** Intrinsic tendencies (creativity, social, curiosity)

### 3.2 Hooked Model (Nir Eyal)
4-phase habit-forming cycle:
1. **Trigger** (External → Internal) — What prompts the behavior
2. **Action** (Fogg: B=MAP) — The simplest behavior in anticipation of reward
3. **Variable Reward** (Tribe/Hunt/Self) — Unpredictable positive reinforcement
4. **Investment** — User puts something in that improves future loops

### 3.3 B=MAP (BJ Fogg)
Behavior = Motivation × Ability × Prompt
- Behavior occurs when all three converge at the same moment
- Design strategy: Make actions easier (Ability) rather than increasing Motivation
- Prompts only work when Motivation and Ability are sufficient

### 3.4 HEXAD User Types (Andrzej Marczewski)
6 user types based on intrinsic/extrinsic motivation:
- **Philanthropist** — Motivated by purpose and altruism
- **Socialiser** — Motivated by relatedness and social connection
- **Free Spirit** — Motivated by autonomy and self-expression
- **Achiever** — Motivated by mastery and competence
- **Player** — Motivated by extrinsic rewards
- **Disruptor** — Motivated by change and pushing boundaries

### 3.5 6D Framework (Kevin Werbach)
6-step enterprise gamification design process:
1. **Define** business objectives
2. **Delineate** target behaviors
3. **Describe** your players
4. **Devise** activity cycles
5. **Don't forget** the fun (and ethics)
6. **Deploy** appropriate tools

### 3.6 Game Thinking (Amy Jo Kim)
Player-centered design approach:
- Focus on the player's journey from novice to mastery
- Design for skill building, not just engagement
- Create feedback loops that support learning
- Build social structures that enable connection
- Progressive complexity through scaffolding

### 3.7 4 Keys to Fun (Nicole Lazzaro)
4 types of fun that drive engagement:
1. **Hard Fun (Fiero)** — Triumph over adversity, challenge
2. **Easy Fun (Curiosity)** — Wonder, exploration, discovery
3. **People Fun (Amusement)** — Social interaction, collaboration, competition
4. **Serious Fun (Meaning)** — Relaxation, purpose, real-world impact

### 3.8 Gamification of Learning (Karl Kapp)
Key principles for educational gamification:
- Mechanics must serve learning objectives (never distract)
- Bloom's Taxonomy alignment for mechanic selection
- Failure as learning opportunity (safe to fail)
- Mastery-based progression (not time-based)
- Spaced repetition integration
- Retrieval practice over passive review

## 4. Common Terminology

| Term | Definition |
|------|-----------|
| **Badge** | Visual marker of achievement or status |
| **Leaderboard** | Ranked display of participants by score/metric |
| **Points** | Numeric representation of progress or value |
| **Level** | Hierarchical position in a progression system |
| **XP (Experience Points)** | Cumulative progress metric toward leveling |
| **Quest** | Goal-oriented challenge with clear objectives |
| **Streak** | Consecutive-day (or period) engagement counter |
| **Achievement** | Recognition for completing specific criteria |
| **Loot** | Random rewards earned through gameplay |
| **Skill Tree** | Branching progression path with specializations |
| **Prestige** | Reset system that rewards starting over at higher tier |
| **Cooldown** | Time delay before an action can be repeated |
| **Onboarding** | First-time user experience and learning phase |
| **Endgame** | Content and mechanics for max-level/experienced users |
| **Grinding** | Repetitive actions for incremental progress (anti-pattern if purposeless) |
| **NPC** | Non-Player Character (guides, mentors in narrative) |
| **Boss Battle** | High-difficulty challenge at progression milestones |
| **Easter Egg** | Hidden feature or reward discovered through exploration |
| **Buff/Debuff** | Temporary bonus or penalty to player capabilities |
| **Clan/Guild** | Player-formed group for collaboration |

## 5. Gamification vs Game Design vs Serious Games

| Aspect | Gamification | Game Design | Serious Games |
|--------|-------------|-------------|---------------|
| **Context** | Non-game product/service | Entertainment product | Purpose-driven game |
| **Full Game?** | No | Yes | Yes |
| **Goal** | Enhance existing behavior | Create entertainment | Teach or train |
| **Elements Used** | Selected mechanics | Complete game systems | Full game with learning objectives |
| **Example** | Duolingo XP system | World of Warcraft | Foldit (protein folding) |
