# Ethical Gamification Checklist

> **ID:** CL-GM-002
> **Applies To:** All gamification designs, mandatory before any deployment
> **Pass Threshold:** All items must pass (zero tolerance for ethical violations)
> **Squad:** squad-gamification
> **Framework References:** Ethical Design (Marczewski), Persuasive Design Ethics (Fogg)

## 1. Autonomy & Consent

- [ ] **Opt-Out Available:** Users can disable gamification features entirely
- [ ] **Informed Consent:** Users understand what gamification does and how it works
- [ ] **No Forced Participation:** Competitive elements are opt-in, not default
- [ ] **Control Over Data:** Users can see and manage their gamification data
- [ ] **Notification Control:** Users set their own notification preferences
- [ ] **No Confirm-Shaming:** Opt-out language is neutral, never guilting

## 2. No Dark Patterns

- [ ] **No Artificial Scarcity:** Urgency is real, not manufactured ("Only 2 left!" on unlimited items)
- [ ] **No FOMO Exploitation:** Fear of missing out not used as primary motivator
- [ ] **No Social Pressure:** Public failure, shame, or bottom-of-list exposure absent
- [ ] **No Addiction Design:** Natural stopping points exist; no infinite autoplay
- [ ] **No Loss Framing Default:** Progress framed as gains, not potential losses
- [ ] **No Forced Virality:** Social sharing never required for core functionality
- [ ] **No Hidden Costs:** All costs transparent upfront; no bait-and-switch
- [ ] **No Loot Box Gambling:** No paid random rewards with rare items (unless regulated)
- [ ] **No Pay-to-Win:** Paid items provide cosmetic/convenience value, never unfair advantage
- [ ] **No Streak Anxiety:** Streaks have freeze options; breaking a streak is not punished harshly

## 3. Vulnerable Populations

- [ ] **Minor Protection:** If minors use the system, age-appropriate mechanics only
- [ ] **No Predatory Monetization:** No mechanics targeting impulsive spending
- [ ] **Addiction Risk Assessment:** Mechanics reviewed for addictive potential
- [ ] **Mental Health Consideration:** No mechanics that could exacerbate anxiety or depression
- [ ] **Accessibility:** All gamification accessible to users with disabilities
- [ ] **Cultural Sensitivity:** Mechanics appropriate across all user cultures

## 4. Transparency

- [ ] **Algorithm Transparency:** Users can understand how scoring and ranking work
- [ ] **Reward Probability Disclosure:** If rewards are random, probabilities are stated
- [ ] **Data Usage Clarity:** Clear explanation of what data gamification collects
- [ ] **No Hidden Manipulation:** No undisclosed psychological techniques
- [ ] **Feedback Mechanism:** Users can report concerns about gamification mechanics

## 5. Fairness

- [ ] **Equal Opportunity:** All users can achieve meaningful progress regardless of spending
- [ ] **No Demographic Bias:** Mechanics don't inadvertently favor specific demographics
- [ ] **New User Fairness:** New users can participate meaningfully (not permanently behind)
- [ ] **Time Zone Fairness:** Deadlines and resets account for global user base
- [ ] **Disability Fairness:** Users with disabilities not disadvantaged by mechanics

## 6. Wellbeing

- [ ] **Healthy Engagement:** Mechanics encourage balanced use, not obsessive use
- [ ] **Sleep Protection:** No notifications or deadlines during sleep hours
- [ ] **Break Encouragement:** System suggests breaks after extended sessions
- [ ] **Positive Failure:** Failure is framed as learning, never as personal inadequacy
- [ ] **Self-Improvement Focus:** Competition encourages self-improvement, not others' failure
- [ ] **Real-World Balance:** Gamification does not incentivize neglecting real-world responsibilities

## 7. Enterprise-Specific Ethics (if applicable)

- [ ] **Not Surveillance:** Gamification tracks outcomes, not minute-by-minute activity
- [ ] **No Unpaid Overtime:** Mechanics don't incentivize working outside paid hours
- [ ] **Power Dynamic Awareness:** Manager presence on leaderboards considered carefully
- [ ] **Union/Labor Compliance:** Reviewed against labor agreements
- [ ] **No Job Security Threat:** Low gamification scores never factor into termination
- [ ] **Voluntary Participation:** Employees not penalized for non-participation

## 8. Learning-Specific Ethics (if applicable)

- [ ] **Learning Over Points:** Mechanics encourage genuine learning, not gaming for grades
- [ ] **No Test Anxiety Amplification:** Assessment gamification reduces, not increases, stress
- [ ] **Academic Integrity:** Gamification doesn't incentivize cheating or shortcuts
- [ ] **Growth Mindset:** Failure messaging encourages persistence, not fixed-mindset responses
- [ ] **Teacher Autonomy:** Educators can adjust or disable mechanics for their context
