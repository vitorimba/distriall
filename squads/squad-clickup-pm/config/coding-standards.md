# Coding Standards — ClickUp PM Squad

## Naming Conventions
- **Tasks:** Verbo + Objeto — "Implementar login OAuth" (not "Login")
- **Branches:** `feat/{task-id}-{slug}`, `fix/{task-id}-{slug}`
- **Commits:** Conventional commits — `feat:`, `fix:`, `docs:`, `chore:`
- **Sprints:** "Sprint {N}" — sequential numbering
- **Epics:** "epic: {descrição}" — prefixed

## Task Standards
- TODA task tem: título claro, descrição, AC, DoD checklist
- Subtask é atômica: 1 ação, max 4h de trabalho
- Labels padronizados: tipo (feature/bug/chore/spike), área, prioridade
- Dependências sempre explícitas

## Estimation
- Story Points: Fibonacci (1, 2, 3, 5, 8, 13)
- Subtask max: 4h
- Sprint capacity: total - buffer (20%)

## Meeting Standards
- TODA reunião: agenda, timebox, output esperado
- Ação sem dono não é ação
- Follow-up em 24h como tasks no ClickUp

## Report Standards
- Métricas com contexto (tendência + comparação)
- Reports acionáveis (dados + sugestões)
- Transparência total (sem sugar coating)
