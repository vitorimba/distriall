# Tech Stack — ClickUp PM Squad

## Project Management
- **Platform:** ClickUp
- **Methodology:** Scrum adaptado (2-week sprints)
- **Frameworks:** Scrum + Kanban + Shape Up + GTD

## Integrations
- **VCS:** GitHub (branch naming: `feat/{task-id}-{slug}`)
- **Communication:** Slack (channels: #project, #blockers, #releases)
- **Database:** Supabase (migration tracking)
- **Deployment:** Vercel

## Metrics
- **Sprint:** Velocity, Commitment Rate, Burndown, Scope Creep
- **Flow:** Cycle Time, Lead Time, Throughput, WIP
- **Quality:** Bug Rate, Escaped Bugs, Rework Rate

## ClickUp Configuration
- **Hierarchy:** Workspace → Space → Folder → List → Task → Subtask → Checklist
- **Statuses:** To Do → In Progress → In Review → QA → Done
- **Custom Fields:** Story Points, Sprint, Epic, Priority, Assignee, Due Date
- **Sprint Length:** 2 weeks (10 working days)
