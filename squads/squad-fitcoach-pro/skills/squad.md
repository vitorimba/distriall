# FitCoach Squad Skills

## Available Skills

### Agent Activation
- `/FitCoach:agents:fitcoach-chief` — Ativar orchestrador
- `/FitCoach:agents:{agent-name}` — Ativar agent específico

### Task Execution
- `/FitCoach:tasks:{task-name}` — Executar task

### Mind Consultation
- `/FitCoach:minds:{mind-name}:artifacts:VOICE_DNA` — Consultar Voice DNA
- `/FitCoach:minds:{mind-name}:heuristics:{CODE}` — Consultar heurística

### Template Usage
- `/FitCoach:templates:{template-name}` — Usar template

### Checklist Validation
- `/FitCoach:checklists:{checklist-name}` — Executar checklist

## Quick Start
1. Ativar: `/FitCoach:agents:fitcoach-chief`
2. O orchestrador roteia para o agent correto
3. Tasks e templates são usados automaticamente
